## `tool_catflow`
The `tool_catflow` container (Manoj J and Dolich, 2025) provides preprocessing tools for the CATFLOW hydrological model (Zehe et al., 2001). It supports the transformation of geospatial raster datasets into hydrological model inputs. These tools build upon an existing CATFLOW preprocessing package developed in R, which has been successfully applied in previous studies.
