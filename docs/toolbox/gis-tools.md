## `tool_whiteboxgis`
`tool_whiteboxgis` (Manoj J et al. 2026) is built around the open-source Whitebox Geographic Information System (GIS). WhiteboxTools is a widely used geospatial analysis platform that supports tasks such as watershed delineation, flow accumulation analysis, stream network extraction, terrain characterization, and digital elevation model (DEM) processing (Lindsay, 2016). By packaging these capabilities in a standardized Python container interface, the tool can be integrated into reproducible geoscientific workflows and combined with other containerized processing steps, independently of the execution environment.
